## 1. Overview

GitHub's Search API does not provide a weekly star-increment metric. This project uses a transparent approximation: **repositories created in the last 7 days, ranked by their current star count**. Every run rewrites this homepage and preserves a dated archive.

**Last updated:** 2026-11-19 00:22 (北京时间), automatically generated.

## 4. 它是怎么工作的

- `scripts/fetch_trending.py`:调用 GitHub Search API,取「最近 7 天新建、按 star 排序」的前 10 个仓库,重写本 README 并存档到 `archives/`。
- `.github/workflows/update.yml`:GitHub Actions 每周一上午(北京时间)自动运行脚本,有变化就自动 commit。
- 口径说明:GitHub API 不提供「本周 star 增量」,故采用「本周新建项目 star 数」作为热度近似,与多数 trending 榜单做法一致。
